# استوديو كتاب التلوين (Coloring Book Studio)

تطبيق ويب بواجهة عربية (RTL) يولّد كتب تلوين قابلة للطباعة: غلاف ملوّن بالألوان الكاملة + عدد من صفحات التلوين بالأبيض والأسود، ويصدّرها كملف PDF جاهز للطباعة. يعمل بالكامل على **الطبقة المجانية من Cloudflare** باستخدام Workers AI — لا مفاتيح مدفوعة ولا خدمات خارجية.

## المتطلبات

- حساب Cloudflare مجاني.
- Node.js 18+ (للتطوير والاختبارات فقط).

## النشر (من الهاتف أو الحاسوب)

### الطريقة الأولى: من الحاسوب (الأسرع)

```bash
git clone <رابط-المستودع>
cd coloring-book-studio
npm install
npx wrangler deploy
```

بعد النشر سيطبع Wrangler رابط التطبيق، مثل: `https://coloring-book-studio.<subdomain>.workers.dev`

تحقّق من أنه يعمل:

```bash
curl https://coloring-book-studio.<subdomain>.workers.dev/api/config
```

يجب أن ترى قائمة النماذج مع `passwordRequired`.

### الطريقة الثانية: من الهاتف (GitHub + لوحة Cloudflare)

1. أنشئ مستودعاً جديداً على GitHub باسم `coloring-book-studio` وارفع كل ملفات المشروع من متصفح الهاتف (زر Add file ← Upload files).
2. في لوحة Cloudflare: Workers & Pages ← Create ← Import a repository ← اختر المستودع.
3. أمر النشر (Deploy command): `npx wrangler deploy` (ربط AI يأتي من `wrangler.jsonc`، لا حاجة لإعداد إضافي).
4. اضغط Deploy وانتظر الرابط.

### كلمة المرور (اختياري لكنه مُستحسَن)

إذا تركت التطبيق مفتوحاً للجميع، سيستهلك أي زائر حصتك اليومية. لحمايته:

- من الحاسوب: `npx wrangler secret put APP_PASSWORD`
- من لوحة Cloudflare: Workers ← التطبيق ← Settings ← Variables and secrets ← Add ← اختر **Secret** واكتب الاسم `APP_PASSWORD` والقيمة.
- بعد ضبطها، سيطلب التطبيق كلمة المرور في الخطوة الأولى قبل أي توليد.

## حساب الحصة المجانية (رياضيات موثّقة)

المصدر: صفحة أسعار Workers AI الرسمية — https://developers.cloudflare.com/workers-ai/platform/pricing/ (محدّثة 2026-10-15).
الحصة المجانية: **١٠٬٠٠٠ خلية عصبية (Neurons) في اليوم**، تُصفَّر عند ٠٠:٠٠ UTC، ومشتركة بين كل استخدامات Workers AI في الحساب.

كل الصور تُولَّد بمقاس 1024×1024 (٤ بلاطات 512×512 = ١ ميغابكسل واحد).

| النموذج | الحساب (خلية عصبية/صورة) | الناتج | صور مجانية/يوم |
|---|---|---:|---:|
| FLUX.1 Schnell | ٤×٤٫٨٠ + ٤ خطوات×٩٫٦٠ | ٥٧٫٦ | **١٧٣** |
| FLUX.2 Klein 4B (الافتراضي) | ٤×٢٦٫٠٥ (لا صورة دخل) | ١٠٤٫٢ | **٩٥** |
| FLUX.2 Klein 9B | أول ميغابكسل ١٣٦٣٫٦٤ | ١٣٦٣٫٦٤ | **٧** |
| FLUX.2 Dev | (٤×٣٧٫٥٠)×٢٠ خطوة | ٣٠٠٠ | **٣** |
| Leonardo Phoenix 1.0 | ٤×٥٣٠ + ٢٥×١٠ | ٢٣٧٠ | **٤** |
| Leonardo Lucid Origin | ٤×٦٣٦ + ٢٥×١٢ | ٢٨٤٤ | **٣** |

- مكالمة التخطيط الواحدة (Llama 3.1 8B) تكلّف نحو **١٦١ خلية عصبية** فقط (تقدير ١٦٠٠ رمز دخل + ١٦٠٠ رمز خرج)، أي أنها رخيصة جداً مقارنة بالصور.
- مثال عملي: كتاب من ١٠ صفحات + غلاف بالنموذج الافتراضي ≈ ١١×١٠٤٫٢ + ١٦١ ≈ **١٬٣٠٧ خلايا** — أي نحو **٧ كتب كاملة في اليوم** قبل نفاد الحصة.
- عند نفاد الحصة يعود الخادم بالرمز `429`، فيتوقف التوليد بهدوء ويظهر زر «استئناف الصفحات المتبقية».

> تنبيه: إذا غيّرت Cloudflare أسعارها لاحقاً، حدّث الأرقام في `src/models.js` فقط — فواجهة `/api/config` وعداد الاستهلاك وجدول هذا الملف يقرؤون منها تلقائياً.

## كيف يعمل التطبيق

1. **الفكرة:** تكتب الموضوع، تختار الجمهور وعدد الصفحات والنموذج.
2. **الخطة والتوليد:** نموذج Llama يخطط للكتاب (عنوان + مشاهد بالإنجليزية لتوليد الصور). ثم تُولَّد كل صفحة بتزامن ٢، مع إعادة محاولة عند أخطاء 5xx. كل صورة خام تُحفظ في IndexedDB.
3. **المعالجة في المتصفح:** تحويل رمادي ← عتبة Otsu ← أسود/أبيض نقي ← سُمك خط ← إزالة النقاط ← إطار مستدير. أشرطة التمرير تعيد المعالجة من الصورة الخام **دون أي استدعاء جديد**.
4. **التصدير:** غلاف JPEG ملوّن (العنوان مرسوم بنص Canvas حقيقي فلا أخطاء إملائية أبداً) + صفحات تلوين ١-بت مضغوطة Flate، صفحات مربعة ٨٫٥ بوصة بدقة ٣٠٠ نقطة/بوصة، مع خيار صفحة ظهر فارغة.

## تغيير النماذج

كل النماذج مسجّلة في `src/models.js` (المعرّف، نوع الدخل JSON/multipart، عدد الخطوات، التكلفة). لإضافة نموذج:

1. أضف مدخلة إلى مصفوفة `MODELS` مع `neuronsPerImage` من صفحة الأسعار الرسمية.
2. إذا كان النموذج يقبل `negative_prompt`، ضع `supportsNegativePrompt: true` (حالياً لموديلات Leonardo فقط).
3. إذا كان يقبل `seed`، ضع `supportsSeed: true`.
4. سيظهر النموذج تلقائياً في قائمة التطبيق مع تقدير الصور/يوم.

ملاحظة: موديلات FLUX.2 Klein تستقبل مدخلات multipart (FormData) بحسب توثيق Cloudflare الرسمي، بينما Schnell وDev وPhoenix وLucid تستقبل JSON.

## الاختبارات

```bash
npm test
```

تغطي الاختبارات: تحليل الخطة، تحويل أخطاء الحصة إلى 429، بوابة كلمة المرور، تمييز نوع الصورة من البايتات، رياضيات الخلايا العصبية، معالجة الصور (Otsu، السُمك، إزالة النقاط، الإطار)، وكاتب PDF.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `429 quota` | انتهت الحصة اليومية — ستُصفَّر عند ٠٠:٠٠ UTC. استأنف غداً. |
| `401` | كلمة المرور غير صحيحة أو ناقصة (تأكد من رأس `x-app-password`). |
| `502 upstream` | فشل مؤقت في Workers AI — أعد المحاولة، والتوليد يعيد المحاولة تلقائياً. |
| النموذج يرفض بارامتراً | الخادم يعيد المحاولة مرة واحدة بالموجّه فقط. |
| الصور لا تُحفظ بعد إعادة التحميل | تأكد أن المتصفح يسمح بـ IndexedDB (ليس وضع التصفح الخاص المقيد). |
